# Modo PLAN

O modo PLAN é utilizado para estruturar ideias antes da implementação.

## Objetivo

Definir claramente:
- Problema
- Solução
- Etapas de execução

##  Exemplo de uso

Prompt:
"Crie um plano para desenvolver uma API de autenticação"

Resposta esperada:
- Definição de requisitos
- Escolha de tecnologia
- Modelagem de dados
- Rotas da API
- Segurança (JWT)

##  Benefícios

- Redução de retrabalho
- Clareza no desenvolvimento
- Melhor organização do projeto
