# AI Copilot - Projeto DIO

Este projeto explora o uso da Inteligência Artificial como um copiloto no desenvolvimento de software, auxiliando na criação de novas features de forma mais rápida e eficiente.

A IA é utilizada para:
- Sugerir soluções
- Gerar código
- Validar ideias
- Automatizar tarefas repetitivas

## Objetivo

Aumentar a produtividade, reduzir erros e acelerar o ciclo de entrega do projeto.

## Estrutura

- modo-Plan.md → Planejamento com IA
- modo-agent.md → Execução com agentes
- modo-ask.md → Uso da IA como assistente
- modo-Study.md → Aprendizado com IA
- docs/links-uteis.md → Materiais de apoio
