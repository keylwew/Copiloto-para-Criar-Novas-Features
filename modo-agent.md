#  Modo AGENT

Neste modo, a IA atua como um agente executor de tarefas.

##  Objetivo

Automatizar partes do desenvolvimento.

##  Exemplos

- Criar código automaticamente
- Refatorar funções
- Gerar testes

##  Prompt de exemplo

"Crie uma função em JavaScript que valide um e-mail"

##  Resultado esperado

Código pronto para uso, como:

```javascript
function validarEmail(email) {
  return /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email);
}
